**Aether** — All-in-one personal tracking & productivity PWA

A fully offline-capable Progressive Web App for tracking attendance, finances, notes, and more. Install it on any device — no server required.

**Features:**
- **Grid Tracker** — Daily attendance/status tracking with customizable states (Present, Absent, Leave, etc.)
- **Finance Module** — Expense tracking, budgeting, and category-wise breakdowns
- **Notes** — Quick note-taking with rich editing
- **Picture Manager** — Camera capture, image editor, and gallery
- **Calculator & Unit Convertor** — Built-in tools for everyday math
- **Print Engine** — PDF export and print history for grids, finances, and global archives
- **Analytics** — Visual insights across all modules
- **Profile & Settings** — Multi-user support, themes (light/dark), internationalization
- **Recycle Bin** — Soft-delete with recovery
- **Lock Screen** — Password protection with forgot-password recovery

**Tech:**
- Zero dependencies — vanilla JS, no build step, no framework
- IndexedDB (Dexie.js) for local data persistence
- Service Worker for full offline support
- Works as an installable PWA on mobile & desktop

**Live:** [scallersspark.github.io/Aether](https://scallersspark.github.io/Aether/)
